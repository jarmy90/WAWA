Comité externo — importar respuesta

Pega la respuesta de un modelo (GPT, Grok, Gemini...) o sube el archivo TXT/Markdown. El texto se guarda como dato: nunca se ejecuta y nunca modifica presupuesto, modos ni producción. Se procesa con un parser con allowlist y se conserva el original.

Modo archivo combinado: usa un único archivo con secciones # GPT, # GROK, # GEMINI y opcionalmente # HUMAN_NOTE. Si falta una sección, se importan las restantes.
